❓ Help & Docs

1) Social Media Post

🐦 Twitter-X Post

Interactive dashboard mocking up X/Twitter post cards. Supports real-time text parsing that applies substring highlights, strikethroughs, and click-to-reveal blacked-out spoiler masks. Features customizable Light/Dim/Dark themes and live metric counters.

📈 Insta BSA-Call

Pop Art & Gen Z styled stock alert poster creator. Overlays customizable tickers, prices, and catalyst/risk check bullets onto the bullish chart canvas with location/scale sliders and high-DPI image downloads.

2) Gallery

📡 CCTV Control Center

Security control room dashboard displaying active video streams as CCTV feeds. Features adjustable grid layouts (2x2, 3x3, 4x4, 1+5 Split), retro CRT screen filters, automated stream rotation, live event logs, click-to-audio selection, and double-click client fullscreen overlay.

🎞️ Video Viewer

Video collage with full-screen playback, play/pause controls, animated border effects, and shuffle through 66 video files with maintained playback state.

🖼️ Animation Gallery

Dynamic dashboard for animated content with adjustable grid layouts (2x2, 3x3, 4x4, Masonry). Features cyberpunk theme switching, polaroid frame styles, auto-shuffle timer, and full-screen preview modes.

🖼️ Presentation

Full-screen slideshow presentation with auto-shuffle images, click to pause/resume, and ESC key to show animated Thank You message.

3) Online

🔴 YouTube

Interactive 2-view YouTube live streams receiver. Auto-extracts YouTube video IDs, dynamically scales stream resolution (480p when small to save data, up to 720p HD when focused), with click-to-audio routing controls.

4) Television

📺 Live Television

Vintage wood-cabinet CRT TV featuring Bindsol branding. Access four categories (Business News, Hindi News, Hindi Music, Lifestyle Fashion) dynamically from a single config. Features viewport auto-scaling, customizable cards strip, CRT screen filters, and scanlines.

📻 Radio — Gujarat

Online radio player with cyberpunk Control Deck aesthetic. 18+ Indian stations including Radio Mirchi 98.3, Red FM 93.5, Big FM 92.7, Fever FM 104, Radio City 91.1 and AIR Gujarat stations. Filter by Gujarati / Hindi / English / News. Waveform animation, volume control, CH prev/next, and custom station support.

📡 IP TV

Interactive 3-view live IPTV dashboard receiver. Configurable slots for HLS streams. Click a stream to expand to full viewport with live audio. Auto Cycle mode, CRT scanlines, preset finder and per-feed power controls.

5) Other

📱 Mobile Simulator

A hybrid smartphone mockup (blending features of iOS and Android). Includes an interactive lock screen, home app launcher, and a virtual finger tap tutorial animation that opens the gallery. Double-clicking a grid stream launches a TikTok/Reels vertical feed equipped with heart burst visual reactions, spinning vinyl soundtracks, and gesture controls.

💬 Chat Story Simulator

A smartphone mockup simulation running a WhatsApp-style chat app. Dynamically parses input/chatstory/story.json to replay conversations with typing indicator delays, checkmark receipts, and attachment images. Includes click-to-zoom image lightboxes and interactive send inputs that trigger automated chatbot responses.

🎨 Style Morph Animator

High-speed sequential image-to-video player animating style-transfer frames from assets/gif2video folder. Includes frame-by-frame controls, speed control, loop modes, frame selection, and theme customization.
